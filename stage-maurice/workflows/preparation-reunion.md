# Workflow : préparation de réunion

Agent responsable : gestion-projet. Déclencheur : `/prep-reunion <interlocuteur ou sujet>`.

1. Retrouver l'événement et l'heure (agenda en lecture ; fuseaux Maurice/France explicites).
2. Lire les échanges Gmail liés (lecture seule) et les fichiers du projet.
3. Si l'interlocuteur est un prospect : fiche via `sales-prep` + `prospection-recherche` (sources publiques seulement).
4. Produire une fiche d'une page : contexte, objectif, ordre du jour proposé, 5 questions, risques, prochaines actions.
5. Contrôle qualité : faits sourcés, heure correcte, rien de confidentiel hors périmètre.
6. **Humain** : relecture ; aucune invitation ni message envoyé par le système.

Résultat : fiche dans `documents/sortant/prep-<date>-<sujet>.md`.
