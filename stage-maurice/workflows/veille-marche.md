# Workflow : veille marché / concurrents

Agent responsable : prospection-recherche. Déclencheur : `/veille <thème>`.

1. Définir 3 questions précises (ex. quels secteurs affichent le plus d'offres difficiles à pourvoir ?).
2. Collecter : recherche web, Firecrawl (gratuit), Indeed ; jamais LinkedIn ; noter l'URL et la date de chaque source.
3. Séparer **faits observés** et **inférences**.
4. Contrôle qualité : réouvrir un échantillon de sources, vérifier chiffres et dates.
5. Écrire `rapports/AAAA-MM-JJ_veille-<theme>.md` : 3 informations clés pour Succexa, limites, suites.
6. Automatisation possible plus tard : tâche planifiée hebdomadaire (à valider avec Samaane).

Résultat : note d'une page sourcée.
